### Slide 4: 平台 — 声明式状态机

# 20+ 游戏阶段，一行映射一个流转

```python
# 传统：if-else 硬编码
if phase == NIGHT_BEGIN:
    if guard_alive: next = GUARD_ACTION
    elif seer_alive: next = SEER_CHECK
    ...

# 我们：数据驱动
PHASE_TRANSITIONS = {
    GamePhase.NIGHT_BEGIN: lambda s: GamePhase.GUARD_ACTION_BEGIN,
    GamePhase.WOLF_KILL:   lambda s: GamePhase.SEER_CHECK_BEGIN,
}

PHASE_SKIP_CONDITIONS = {
    GamePhase.GUARD_ACTION: lambda s: not s.is_role_alive(Role.GUARD),
}
```

| 对比 | 传统 | 我们 |
|------|------|------|
| 新增阶段 | 改 N 处 if-else | 加 1 行映射 |
| 角色死亡 | 每个处理器检查 | 自动递归跳过 |
| 条件分支 | 嵌套 if | `Callable[[State], Phase]` |

### Slide 6: 平台 — 可控评测

| 模式 | 策略 | 用途 |
|------|------|------|

### Slide 8: Agent — 四层记忆系统

# 从瞬时到永久，信息逐层沉淀

| 层级 | 名称 | 生命周期 | 内容 |
|------|------|---------|------|
| L1 | Working Memory | 单局 | 当前局事件流、存活状态 |
| L2 | Opponent Model | 跨局 | 对手行为模式、欺骗倾向 |
| L3 | Self Model | 跨局 | 自身策略偏好、角色擅长度 |
| L4 | Game Archive | 永久 | 完整对局记录、胜负归因 |

**三层加载**：全局基线 → 角色特化 → 场景微调

### Slide 9: 核心创新 ① — 去抖策略进化

# 一局胜负不能定义策略好坏

```
传统：输一局 → 立即改策略 → 过拟合 → 下一局又输

我们：缓冲 → 聚类 → 双阈值确认 → 版本竞争
```

**双阈值确认**：

| 通道 | 条件 | 速度 |
|------|------|------|
| 标准通道 | 建议数 ≥ 3 **且** 一致率 ≥ 60% **且** 因果强度 ≥ 0.5 | 慢，稳健 |
| 快速通道 | 建议数 ≥ 5 **且** 一致率 ≥ 80% | 快，高置信 |

**因果强度 vs 置信度分离**：高置信不等于高因果——"每次都输"是高置信，但可能只是运气差。

### Slide 10: 核心创新 ② — GEPA 遗传-帕累托优化

# 四维度同时最优，不是单维度内卷

```
传统：只看胜率 → 策略单一、脆弱

GEPA：胜率 × 一致性 × 欺骗性 × 信息利用
```

**Pareto 前沿选择**：

```
consistency
  1.0 ┤    ●
      │  ●   ●      ● = Pareto 前沿（各维度最强）
  0.6 ┤●   ○   ●    ○ = 被支配个体
      │  ○     ○
  0.0 ┼──────────── win_rate
```

**LLM 驱动的变异与交叉**：不是随机扰动，而是语义级别的策略改写。

### Slide 11: 核心创新 ③ — 共轭 Agent 人格进化

# 策略是基因，共轭体是基因组快照

```
策略 v1.2 ──晋升──► 新共轭体诞生
                    │
                    ├── 名字：默夜 → 烬语 → 霜鉴 → 烛影 → 烙痕
                    ├── 指纹：{角色分布, 模型, 核心策略hash}
                    └── 人格：LLM 基于指纹生成个性化表达风格
```

**进化不再抽象，而是可视的、可叙事的**：

- 每个人格有名字、有历史、有个性
- 策略晋升 = 新人格诞生，不是覆盖旧版本
- 旧人格可回溯、可对比、可回滚

### Slide 15: 技术创新总结

# 五大核心创新

| # | 创新 | 一句话 |
|---|------|--------|
| 1 | **去抖策略进化** | 缓冲→聚类→双阈值确认，避免过拟合 |
| 2 | **因果强度分离** | 高置信 ≠ 高因果，分离避免伪进化 |
| 3 | **GEPA 帕累托优化** | 四维度同时最优，Pareto 前沿保留多样性 |
| 4 | **共轭 Agent 人格** | 策略晋升 = 新人格诞生，进化可视可叙事 |
| 5 | **四层记忆 + 三层加载** | 瞬时→永久逐层沉淀，全局→场景逐层特化 |
